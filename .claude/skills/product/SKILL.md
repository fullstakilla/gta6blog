# GTA6·БЛОГ — Продукт

## Что это

Новостной фан-хаб про GTA VI на русском языке. Публикация редакционных статей, комментарии, реакции, галерея, email-подписка, живой таймер до релиза.

**Не форум, не соцсеть, не энциклопедия транспорта/оружия.** Один жанр — редакционный блог с элементами tracker.

## Аудитория

- **География**: СНГ, основной язык — русский.
- **Кто**: фанаты серии GTA, следящие за релизом GTA VI (Rockstar, Take-Two).
- **Что ищут**: разборы трейлеров, утечки, слухи, теории, детали мира — без хайпа и кликбейта.
- **Возраст**: 18–35, мужская аудитория преобладает (не эксклюзивно).
- **Устройства**: desktop + mobile ≈ 50/50, поэтому mobile-адаптив обязателен с первого дня.

## Позиционирование

**«Без хайпа. Без кликбейта. Editorial.»**

Отстройка от reddit-мусора и youtube-скам-каналов. Аналог по духу: The Verge для геймдева, но underground.

## Tone-of-voice

**Что делаем:**
- Заголовки конкретные, глагольные: «Полная карта Vice City слита в сеть», «Кто такая Люсия».
- Фактическая meta: «47 подтверждённых фактов, 23 надёжные утечки, 12 официальных трейлеров».
- **Весь UI и контент — на русском.** См. `design-system` раздел «Копирайт и язык». Английский только для имён собственных (GTA VI, Vice City, Rockstar, Take-Two, PS5, Xbox), технических констант (`TRAILER`, `LEAK` в БД) и splash-код-эстетики.

**⚠️ Историческая заметка:** ранее в дизайне был bilingual editorial (Latest dispatches, Get the dispatch и т.д.) — приём вырезан 2026-09-01 после ревью: массовая СНГ-аудитория GTA (в т.ч. школьники и студенты) считывает такое как pretentious/foreign. Не возвращать без явного продуктового решения.

**Чего избегаем:**
- CAPS-Locked заголовки в стиле «ШОК! РОКСТАР СЛИЛА…»
- Emoji в UI и заголовках статей.
- Восклицательные знаки в meta.
- «Уникальные скидки», «только сегодня», продающие формулировки — это не e-commerce.
- Оценочные «лучший/худший» без обоснования.

## Целевые метрики MVP

Ранжирование по приоритету:

1. **Уники/день** — базовый охват.
2. **Глубина просмотра (страниц/сессия)** — работа связей, «похожие», featured.
3. **% возвращающихся** — retention. За это отвечают 5 фишек удержания (см. skill `retention-features`) + email.
4. **Email-подписчики** — второй канал возврата.
5. **Время на «Всё что известно»** (evergreen-страница) — качество главного long-form.

Комменты/реакции — метрика вовлечённости, не первичная.

## Монетизация

**В MVP:** пустые слоты (`AD · 728×90`, `AD · 300×250`), зарезервированные в дизайне. НЕ подключаем adsense/РСЯ до первых 10K уников/день.

**Дальше:** прямые интеграции с игровыми площадками, партнёрские материалы (с меткой), нативная реклама трейлеров/мерча. Никаких попапов, автоплеющих видео, taboola-widgets.

## Правовой контекст

- **Unofficial fan site.** Обязательный дисклеймер в футере: `GTA VI © ROCKSTAR GAMES & TAKE-TWO INTERACTIVE.`
- Никаких скачиваний, ромов, крэков, читов, ссылок на пиратские билды.
- Утечки — только описание, разбор. Не хостим сами файлы утечек.
- 152-ФЗ / GDPR: IP хранить как `sha256(ip + salt)`, email только с явного согласия.

## Что делаем в MVP

Публичный сайт:
- Главная (реализована)
- Список блога с фильтрами
- Статья + комменты + реакции + похожие
- Галерея с модалкой
- О проекте + Privacy + Cookies
- Email-подписка

Админка:
- Login (JWT)
- Список статей + редактор
- Модерация комментов
- Простая dashboard-статистика

Бэк (**Next.js Server Actions + Prisma + PostgreSQL**, БЕЗ отдельного Go-сервиса — см. skill `decisions`):
- CRUD статей, реакции, комменты, подписчики
- Rate limits, sanitize, iron-session auth

## Что НЕ делаем в MVP (важно!)

Не предлагать пользователю и не начинать без явного запроса:

- Личный кабинет / регистрация пользователей
- Форум / треды / сообщества
- Интерактивная карта Vice City
- База транспорта / оружия / персонажей (структурированные data-объекты)
- Мобильное приложение
- Мерч, донаты, Patreon
- Мультиязычность (только ru)
- Светлая тема
- Страницы авторов (имя в статье — достаточно)
- Рекомендательная система (только «похожие по тэгам»)
- Полнотекстовый поиск (только фильтры по категориям/тэгам)
- Push-уведомления
- Дискорд-бот / TG-бот

Всё это — **вторая волна** после первых метрик. Если пользователь просит одно из этого — уточни, точно ли сейчас, или можно во вторую волну.

## Категории статей

Фиксированный список (используется в фильтрах, БД, тэгах):

- `TRAILER` — разборы трейлеров, тизеров
- `LEAK` — утечки (описание, без хостинга)
- `MAP` — карта, локации, открытый мир
- `CHARACTER` — персонажи (Люсия, Джейсон, второстепенные)
- `GAMEPLAY` — механики, боевая система, кооп
- `RUMOR` — слухи, теории (с явной пометкой)

**Не добавлять** новые категории без явного продуктового решения. Тэги (`tags text[]`) — свободные, для узких срезов.

## Roadmap ориентиры

- **MVP (2 недели)**: главная + блог + статья + галерея + admin + email + SEO

- **v2 (3 месяца)**: рекомендации, интерактивная карта, комьюнити
